# 🚀 Instruções de Ativação do GitHub Pages (`bruno-olivaes.github.io`)

O repositório especial **`bruno-olivaes.github.io`** foi criado e o código do seu site acadêmico já foi enviado para a branch `main`.

Como este repositório possui o nome padrão `<username>.github.io`, o GitHub Pages já publica automaticamente o site na raiz do domínio:
👉 **[https://bruno-olivaes.github.io](https://bruno-olivaes.github.io)**

---

## ⚙️ Passo a Passo para Garantir a Ativação

Caso o GitHub não inicie o build automaticamente, siga estes passos simples:

1. Acesse o painel de configurações do repositório:
   👉 **[https://github.com/bruno-olivaes/bruno-olivaes.github.io/settings/pages](https://github.com/bruno-olivaes/bruno-olivaes.github.io/settings/pages)**

2. Na seção **"Build and deployment"**:
   - **Source:** Selecione **"Deploy from a branch"**.
   - **Branch:** Selecione **`main`** e mantenha a pasta como **`/ (root)`**.
   - Clique no botão **Save**.

3. Aguarde cerca de 1 a 2 minutos para que o GitHub Actions conclua o deploy inicial.

4. Acesse:
   🌐 **[https://bruno-olivaes.github.io](https://bruno-olivaes.github.io)**
